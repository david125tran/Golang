## Commands
- Build executable
    - cd to project root
    - Turn project into a module:  
        `go mod init <module name>`
    - Build the executable:  
        `go build`
- Run executable in terminal
    - cd to project root
    - Run the executable from terminal:  
        `./<executable name>`  **(Do not include '.exe' at end)**
